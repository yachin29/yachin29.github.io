# WebP Bulk Converter（一括 WebP 変換＆リサイズツール）仕様書

## 1. アプリ概要
複数の JPG / PNG / GIF / WebP 画像をブラウザ上で一括して WebP 形式に変換・リサイズ・圧縮し、個別または ZIP でまとめてダウンロードできる Web 制作者向けツール。
外部サーバーへのアップロードを一切行わず、ブラウザ標準の Canvas API のみで完結するため、未公開案件の画像も安全・高速に処理できる。

## 2. 技術スタック・構成
- **構成:** ビルド不要の静的Webサイト（`index.html`, `script.js`）
- **スタイリング:** Tailwind CSS（Play CDN: `https://cdn.tailwindcss.com`、`darkMode: 'class'` 設定）
- **ZIP生成ライブラリ:** JSZip（CDN: `https://cdnjs.cloudflare.com/ajax/libs/jszip/3.10.1/jszip.min.js`）
- **デザインテイスト:** 前作の `clamp()` ツールと統一したモダンなカードUI（`slate-900` / `indigo-500` 基調、ライト/ダークモード切替付き）

## 3. コア機能要件

### 3.1 変換設定（Settings）
1. **画質（Quality）設定:**
   - レンジスライダー（`1` 〜 `100`、初期値 `80`）と現在の数値表示（`80%`）。
   - ワンクリックプリセットボタン：`75%（軽量）` / `80%（標準）` / `90%（高画質）`（選択中のプリセットが視覚的に分かる状態にする）。
2. **最大横幅リサイズ（Max Width）:**
   - チェックボックス「最大横幅を指定してリサイズする」（初期値 OFF）。
   - 数値入力欄（初期値 `1920` px）＋ ワンクリックプリセット（`1200px` / `1920px` / `2560px`）。
   - **拡大防止ルール:** 元の画像幅が指定値以下の場合は引き伸ばさず、元のサイズを維持する（アスペクト比は自動維持）。
3. **ファイル名オプション:**
   - 拡張子を `.webp` に置換（例: `photo.jpg` → `photo.webp`）。
   - 任意の接尾辞（例: `-min`）を追加できるテキスト入力欄（初期値空欄）。
   - 重複ファイル名対策：同名ファイルが複数ある場合は `photo(1).webp` のように自動連番して ZIP 内での上書きを防ぐ。
4. **設定変更時の自動再変換:**
   - すでに画像がドロップされた状態で画質・最大横幅・接尾辞を変更した場合、リスト内の全画像を自動的に再変換してファイルサイズ・削減率・ファイル名を即時更新する。

### 3.2 複数ファイルの一括ドロップ＆追加（Dropzone）
- ドラッグ＆ドロップエリア、およびクリックでのファイル選択（`<input type="file" accept="image/jpeg,image/png,image/gif,image/webp" multiple>`）。
- すでにリストに画像がある状態でさらに追加ドロップした際、既存リストをリセットせず末尾に追加する。
- キーボード操作（Enter / Space でファイル選択ダイアログ起動）にも対応。

### 3.3 一括変換処理（Canvas API）
- `createImageBitmap`（または `Image`）と `<canvas>` を使用し、`canvas.toBlob(callback, 'image/webp', quality / 100)` で非同期に WebP Blob を生成。
- PNG の透過（アルファチャンネル）はそのまま維持する。
- 大量（20〜50枚）投入時も UI がフリーズしないよう、1枚ずつ非同期で順次処理しながら進捗ステータス（例：`変換中... 12 / 30枚`）を表示する。

### 3.4 変換結果リスト＆一括ダウンロード（Result List & ZIP）
- **サマリーバー:**
  - 合計枚数、変換前合計サイズ → 変換後合計サイズ、全体の削減率（例：`合計 12枚 | 18.4 MB → 2.1 MB (-88%)`）。
  - **「📦 ZIPで一括保存」ボタン**（JSZip で `webp-images.zip` としてまとめてダウンロード）。
  - **「すべてクリア」ボタン**（メモリ解放のため `URL.revokeObjectURL` も実行）。
- **ファイル一覧リスト（ビフォー・アフター比較プレビューは不要・シンプル一覧）:**
  - サムネイルプレビュー（48×48px程度、透過が分かるチェッカーボード背景推奨）
  - 変換後ファイル名 ＆ 出力解像度（例：`1920 × 1080`）
  - サイズ変化と削減率バッジ：
    - 削減できた場合：`2.4 MB → 310 KB` ＋ 緑色バッジ `[-87%]`
    - **元ファイルよりサイズが増えた場合：** そのまま `.webp` として出力しつつ、注意色の警告バッジ（例：オレンジ系で `[+12% 増加]`）を表示する。
  - 個別ダウンロードボタン（単体 `.webp` 保存）＆ リストからの個別削除ボタン。
