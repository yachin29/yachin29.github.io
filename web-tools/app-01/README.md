# Min-Max clamp() Calculator

デザインカンプのサイズとビューポート幅から、CSS `clamp()` を生成する静的なWebツールです。

## 使い方

`index.html` をブラウザーで開くか、GitHub Pages などの静的ホスティングに配置してください。Tailwind CSS は CDN から読み込むため、ビルド手順はありません。

- サイズ範囲と画面幅を入力すると、`clamp()` とプレビューが更新されます。
- ヘッダーでライトモードとダークモードを切り替えられます。`rem` 換算の基準は `1rem = 16px` です。
- URLのクエリに `?16,24,400,1200` の形式で値を指定すると、入力内容を共有できます。
- 画面幅スライダー、編集可能なテキスト、px/rem変換、コードコピーを利用できます。

クリップボードへのコピーは、HTTPSまたはlocalhostなど、Clipboard APIが許可される環境で利用できます。
