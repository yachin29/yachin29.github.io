4. 機能要件・計算ロジック仕様4.1 ルートフォントサイズ設定（rootSize）デフォルト値は 16（px）。数値入力フィールドのほか、ワンクリックで切り替えられるプリセットボタン 16px（標準）と 10px（html { font-size: 62.5%; } 運用向け）を用意する。変更時、すべての rem 表示および clamp() 出力が即座に再計算されること。4.2 clamp() 関数算出ロジック入力パラメータ：$V_{\min}$: 最小サイズ（px） ※負の値（ネガティブマージン等）も許容$V_{\max}$: 最大サイズ（px） ※負の値も許容$W_{\min}$: 最小画面幅（px）$W_{\max}$: 最大画面幅（px）$R$: ルートフォントサイズ（px）計算式：傾き（Slope）:$$\text{slope} = \frac{V_{\max} - V_{\min}}{W_{\max} - W_{\min}}$$Y切片（Y-Axis Intersection）:$$y = -W_{\min} \times \text{slope} + V_{\min}$$各値の単位変換と丸め処理（小数点第4位まで、末尾の不要な 0 は削除）:$\text{minRem} = \text{round}(V_{\min} / R, 4)$$\text{maxRem} = \text{round}(V_{\max} / R, 4)$$\text{yRem} = \text{round}(y / R, 4)$$\text{slopeVw} = \text{round}(\text{slope} \times 100, 4)$ネガティブ値対応（Min / Max の順序保証）:CSS の clamp(MIN, VAL, MAX) は MIN <= MAX である必要があるため、負の値入力時でも破綻しないよう Math.min(minRem, maxRem) と Math.max(minRem, maxRem) を第1・第3引数に配置する。推奨値（Preferred Value）の符号整形:slopeVw >= 0 の場合: ${yRem}rem + ${slopeVw}vwslopeVw < 0 の場合: ${yRem}rem - ${Math.abs(slopeVw)}vw最終出力フォーマット:通常: clamp(${clampMin}rem, ${preferred}, ${clampMax}rem)「font-size: を付ける」チェック時: font-size: clamp(${clampMin}rem, ${preferred}, ${clampMax}rem);4.3 URL クエリパラメータ同期（9elements 互換）読み込み: ページ初期表示時、?16,24,400,1200 の形式でクエリパラメータが存在する場合、カンマ区切りで [minVal, maxVal, minVw, maxVw] として各入力欄に自動セットする。書き出し: 入力値が変更されるたびに、window.history.replaceState を用いて URL のクエリパラメータを ?${minVal},${maxVal},${minVw},${maxVw} に更新する（ブックマークやURL共有を容易にするため）。4.4 リアルタイム挙動プレビューレンジスライダー（min="320" max="1600"）を操作すると、指定画面幅における実際の計算結果（px および rem）を表示し、プレビュー枠内のサンプルテキストの font-size をリアルタイムに変化させる。サンプルテキストはユーザーが直接編集可能（contenteditable="true"）にすると実用性が高まる。4.5 単発 px ⇄ rem クイック変換px 入力欄と rem 入力欄を双方向にバインディングし、どちらか一方を入力するともう一方の数値がリアルタイムに変換される。5. Tailwind CSS 実装ガイドライン（Copilot への指示）Tailwind CDN の読み込み:index.html の <head> 内に <script src="https://cdn.tailwindcss.com"></script> を記述し、外部 CSS ファイルを作らずに Tailwind のユーティリティクラスのみで完結させること。フォーカス・ホバー体験:数値入力フィールド（<input type="number">）は font-mono を適用し、フォーカス時に focus:outline-none focus:ring-2 focus:ring-indigo-500 focus:border-indigo-500 のように明確なフィードバックを付けること。コピーボタンのフィードバック:クリップボードへのコピー成功時（navigator.clipboard.writeText）、ボタンのテキストを「コピー完了!」に変更し、背景色を緑系（bg-emerald-600）に 1.5 秒間切り替えてから元に戻すこと。ゼロ除算・不正値ガード:minVw === maxVw の場合や入力欄が空欄（NaN）になった場合でも、画面に NaN や Infinity が表示されないよう適切にフォールバック処理を行うこと。6. 実装ステップ（VS Code での進め方）本ファイルをプロジェクト内の .github/copilot-instructions.md または SPEC.md として保存する。Copilot Chat（Agent モード）を開き、以下のように指示して生成を実行する：「SPEC.md の仕様に従って、Tailwind CSS を使った index.html と script.js を作成してください。」ブラウザ（Live Server など）で表示・計算・URLパラメータ動作を確認し、必要に応じて微調整を行う。
