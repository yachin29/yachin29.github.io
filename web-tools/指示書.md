# Web Dev Tools Portal（自作Web制作ツール集ポータル）仕様書

## 1. サイト概要・公開URL
- **サイト名:** Web Dev Tools（yachin29 Web Creator Suite）
- **公開URL:** `https://yachin29.github.io/web-tools/`
- **概要:** Web制作・コーディングの実務で使えるブラウザ完結型の自作ツール群を一覧・検索・起動できるポータルサイト。
- **デザインテイスト:** 配下の各ツール（`app-01`, `app-02`）と統一したモダンなカードUI（Tailwind CSS、`slate-50` / `slate-950` 背景、`indigo-500` アクセント、ライト/ダークモード切替付き）。

## 2. ディレクトリ・ファイル構成
`web-tools/` 直下にポータル本体を配置し、各サブディレクトリへ相対パスでリンクする構成とする。

```text
web-tools/                  （公開ルート: [https://yachin29.github.io/web-tools/](https://yachin29.github.io/web-tools/)）
├── SPEC.md                 （本仕様書）
├── index.html              （ポータルページHTML）
├── script.js               （ツール一覧データ管理・検索・フィルタ・テーマ切替）
├── app-01/                 （Min-Max clamp() Calculator）
├── app-02/                 （WebP Bulk Converter）
└── code-work/              （コーディング練習・実験用ワークスペース）
