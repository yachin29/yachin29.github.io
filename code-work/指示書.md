# コードタイピング練習Webアプリ（Code-Drill風）開発指示書

この指示書に従い、Webサーバーにアップロードして公開できる、プログラミング学習者向けの「コードタイピング練習Webアプリ」を作成してください。

---

## 1. 技術スタック・ファイル構成
サーバー側でのデータベース（MySQL等）やバックエンド処理（PHP等）は使用せず、以下の **2ファイルのみ** で完結する静的Webアプリとして構築してください。

1. **`index.html`**
   - HTML5 + **Tailwind CSS（Play CDN: `https://cdn.tailwindcss.com`）** + Vanilla JavaScript
2. **`problems.json`**
   - 出題するソースコードの問題データ

---

## 2. 問題データ仕様（`problems.json`）
- カテゴリーは以下の **4種類** とし、それぞれをオブジェクトのキーとして分類してください。
  1. `html`（表示名: HTML）
  2. `css`（表示名: CSS）
  3. `javascript`（表示名: JavaScript）
  4. `jquery`（表示名: jQuery）
- 各カテゴリー内に、実践的で学習効果の高いサンプル問題を **40問ずつ** 収録してください。
- データ構造の例：
```json
{
  "html": [
    {
      "id": 1,
      "title": "HTMLの基本構造とリンク",
      "code": "<div class=\"card\">\n  <h2>お知らせ</h2>\n  <a href=\"https://example.com\">詳細を見る</a>\n</div>"
    }
  ],
  "css": [],
  "javascript": [],
  "jquery": []
}
```

## 3. UI・デザイン要件（Tailwind CSS）
- **全体テーマ**: VS Code風のダークモード基調（`bg-slate-900` や `bg-slate-950` ベース）で、目が疲れにくく洗練されたエンジニア向けのデザインにしてください。
- **フォント**: 見本コード・入力エリアともに見やすい等幅フォント（`font-mono`）を使用し、文字サイズは大きめ（`text-base` 〜 `text-lg`）で視認性を高めてください。
- **ヘッダー＆常時ハイスコア表示**:
  - 画面上部のヘッダーにアプリタイトル、カテゴリー選択タブ（HTML / CSS / JavaScript / jQuery）、モード切り替えタブを配置してください。
  - **現在選択中のカテゴリーの「HIGH SCORE（自己ベストスコア）」をヘッダーの目立つ位置に常に表示**してください（未プレイ時は `0 pt`）。
  - 全4カテゴリーのハイスコア一覧もヘッダー内またはサブバーで一目で確認できるようにしてください。

## 4. プレイモード仕様（2モード切り替え）
画面上部で以下の2つのモードを切り替えられるようにしてください。

### モード①：ひたすら練習モード（エンドレス・時間制限なし）
- **目的**: 生徒が自分のペースでじっくりコードを打ち込む練習をするモード。
- **仕様**:
  - 制限時間なし。スコア計算は行わず、代わりに「現在のWPM」「正答率（%）」「クリア済み問題数」を表示します。
  - ドロップダウンまたは問題番号リストから、好きな問題に直接ジャンプして練習することも可能です。
  - 1問クリアするごとに自動で次の問題へ進みます（40問目まで行ったら1問目にループ）。
  - クリアした問題IDは `LocalStorage` に保存し、問題セレクタ等に「クリア済みチェックマーク（✓）」を表示してください。

### モード②：10分ハイスコアモード（タイムアタック）
- **目的**: 10分間の制限時間内で何問クリアできるかを競い、スコアを他者と比較するモード。
- **仕様**:
  - モード選択後、「10分チャレンジ開始！」ボタンを押すと **10:00（600秒）のカウントダウンタイマー** がスタートします（開始前は入力欄をロック）。
  - **スコア計算ロジック**: 1問完全一致でクリアするごとに、以下の点数を加算してください。
    - 基本点: `1000 pt`
    - 文字数ボーナス: `見本コードの文字数 × 10 pt`
    - ノーミスボーナス: `300 pt`（その問題で1度もタイプミスしなかった場合）
  - **リアルタイムハイスコア更新**: プレイ中の合計スコアが `LocalStorage` に保存されている該当カテゴリーのハイスコアを超えた瞬間、ヘッダーのハイスコア表示もリアルタイムで更新し、「NEW RECORD!」のバッジを表示してください。
  - **タイムアップ＆リザルト画面**:
    - 残り時間が `00:00` になったら即座に入力をロックし、画面中央に大きなリザルトモーダルを表示してください。
    - リザルトモーダルには、クラスメイトと画面を見せ合って比較しやすいよう、**「カテゴリー名」「最終スコア（特大フォント）」「自己ベスト（HIGH SCORE）」「クリア問題数」「平均WPM」「ランク判定（S / A / B / C）」**を表示してください。
    - 「もう一度挑戦する」「練習モードへ戻る」ボタンを配置してください。

## 5. タイピング画面の操作・判定ロジック（両モード共通）
1. **上下2段レイアウト**:
   - **上段（見本コード表示エリア）**: お手本コードを表示します。下段の入力文字と1文字ずつリアルタイムに比較し、以下の色分けを行ってください。
     - 入力済みかつ正解の文字：緑色（`text-emerald-400`）
     - 次に打つべき1文字（カーソル位置）：背景ハイライト（`bg-amber-400/30 border-b-2 border-amber-400`）
     - 間違って入力された文字：赤色背景（`bg-rose-500/40 text-rose-200`）
   - **下段（ユーザー入力エリア）**: `<textarea>` を配置してください。
2. **完全一致での自動次問題遷移**:
   - 下段の入力テキストと上段の見本コードが **1文字の狂いもなく完全一致した瞬間**、ボタンを押す操作なしで自動的にクリア判定を行ってください。
   - クリア時は画面上に「CLEAR!（ハイスコアモード時は `+〇〇 pt` も表示）」の短いトースト演出（約0.8〜1.0秒）を表示したあと、**自動的に次の問題へ切り替わり、入力欄がリセットされて即座にタイピングを続行できる**ようにしてください。
3. **入力補助と不正防止**:
   - `<textarea>` 内で `Tab` キーを押した際、フォーカス移動を防ぎ、見本のインデントに合わせた **半角スペース2つ（`  `）** がカーソル位置に挿入されるようにしてください。
   - コピー＆ペースト（`paste` イベント）およびドロップ入力は禁止してください。
   - 改行コード（`\r\n` と `\n`）の差異で一致判定が失敗しないよう正規化して比較してください。

## 6. データ読み込み・保存（LocalStorage / URLパラメータ）
- **問題読み込み**: 起動時に `fetch('./problems.json?t=' + Date.now())` で問題データを非同期読み込みしてください。
- **LocalStorage保存**: 以下のデータをブラウザの `LocalStorage` に保存・復元してください。
  - カテゴリー別のハイスコア（例: `codeDrill_highScores: { html: 0, css: 0, javascript: 0, jquery: 0 }`）
  - 練習モードのクリア済み問題IDリスト（例: `codeDrill_cleared: { html: [], css: [], javascript: [], jquery: [] }`）
- **URLパラメータ対応**: `?category=jquery&mode=attack` のようにURLパラメータ付きでアクセスした場合、指定されたカテゴリー・モードが初期選択された状態で開くようにしてください。
